# Certificación Python - Santander Open Academy 🎓

Este repositorio contiene el material y los proyectos desarrollados durante mi formación en Python. La estructura sigue el plan de estudios del curso para facilitar la navegación.

## 📂 Contenido del Curso

### 📦 Módulo 1
- **1 - Introducción:** Primeros pasos y configuración.
- **2 - Fundamentos:** Sintaxis básica y variables.
- **3 - Estructuras de Control:** Condicionales y bucles.
- **4 - Estructura de Datos:** Manejo de listas y diccionarios.
- **🚀 Mini Proyecto Módulo 1:** Sistema de gestión de estudiantes (CRUD).

### 📦 Módulo 2 (En progreso)
- **5 - Funciones:** Modularización de código.
- **6 - Manejo de Errores:** Try / Except y validaciones.
- **7 - Entradas:** Interacción con el usuario.
- **8 - Módulos:** Importación de librerías y organización.
